# 炒股厉害的人怎么复盘

> 核心理念：**把「结果」还原成「过程」**。复盘不是为了「看懂市场」，而是为了第二天下手能更果断。

---

## 一、先复盘市场结构（判断环境）

每天先定调，决定第二天是**进攻**还是**收缩**。记录 4 个数据：

| 指标 | 记录内容 |
|------|----------|
| 指数 | 涨跌幅 + 是否放量 |
| 涨跌比 | 上涨家数 / 下跌家数 |
| 涨跌停 | 涨停数量 + 跌停数量 |
| 连板高度 | 龙头打到几板 |

### 情绪周期判断

| 阶段 | 特征 | 策略 |
|------|------|------|
| 冰点 | 跌停多、无连板 | 只看低吸试错 |
| 回暖 | 开始有连板 | 可以试探性参与 |
| 加速 | 连板扩散 | 可以主动进攻 |
| 分歧 | 高位炸板 | 控仓 + 去弱留强 |

---

## 二、重点复主线资金（找钱在哪）

很多人复盘板块是「看涨停板」，高手看的是：**谁在持续被资金选择**。

### 具体做法

1. 统计当日涨停个股
2. 按行业/题材分类
3. 看哪个方向出现「重复上榜」

重点不是谁涨得多，而是有没有**持续性**（连续 2–3 天都有资金在打）。

### 进一步观察

- 是龙头带队，还是一盘散沙？
- 是高位加速，还是低位补涨？

**结论：** 明天最可能有机会的方向是？

---

## 三、核心个股拆解（看主力怎么做）

这一部分才是真正的「技术复盘」。挑 3–5 只核心票（龙头/强势股），逐个拆：

### 1. 启动点

- 第一根放量大阳是哪里？
- 当时是消息驱动，还是资金先动？
- **判断：** 是预期驱动，还是情绪驱动？

### 2. 加速段

- 连续上涨阶段，是缩量还是放量？
- 是一字板，还是换手板？
- **判断：** 筹码是锁住，还是在交换？

### 3. 分歧点

- 哪一天开始放量滞涨？
- 哪一天开始炸板？
- **这一步最关键：** 主力是洗盘，还是开始出货？

### 4. 承接验证

- 大跌之后有没有快速收回？
- 下影线多不多？
- **判断：** 有没有人接盘，而不是有没有人卖？

> 你拆多了会发现：强势股的走势，是有「模板」的，这才是复盘的真正价值。

---

## 四、交易复盘表（只改自己的问题）

这一块不是写感受，而是做「行为复盘」。每一笔交易记录 4 点：

| 字段 | 说明 |
|------|------|
| 买点 | 具体 K 线位置 |
| 买入理由 | 一句话逻辑 |
| 是否符合系统 | 是 / 否 |
| 卖出原因 | 止盈 / 止损 / 情绪 |

### 重点看两件事

**1. 错在哪？**

追高？抄底？还是不该加仓了？

**2. 可以优化什么？**

示例规则：

- 以后只做第一次分歧，不做二次分歧
- 缩量加速不追
- 跌破承接位必须走

---

## 五、说在最后

复盘到最后，应能判断三件事：

1. **明天做不做？**
2. **看哪个方向？**
3. **具体盯哪几只？**

如果复盘完这三件事说不清，基本等于白复。

如果不想每天手动筛票，可以用量化工具把符合要求的票先过滤出来，每天看的票不多，但基本都是值得看的。
